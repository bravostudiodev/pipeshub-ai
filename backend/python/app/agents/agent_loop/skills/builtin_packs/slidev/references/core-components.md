# Slidev components

Slidev includes Vue components for layouts, diagrams, code, and interaction.
Useful built-ins include `<v-click>`, `<v-clicks>`, `<Transform>`, `<Arrow>`,
`<LightOrDark>`, and `<RenderWhen>`.

Code blocks can show line numbers and highlighted ranges. Monaco editor and
run-code blocks require additional browser/runtime capabilities and are not
part of this fork's offline rendering contract; prefer static examples.

Use built-in components and local Vue components supplied as supporting
files. Do not add package manifests or external component imports.

Full upstream guide: https://sli.dev/guide/component

# Slidev layouts

Common built-in layouts include `cover`, `intro`, `center`, `default`,
`two-cols`, `two-cols-header`, `image`, `image-left`, `image-right`, `quote`,
`section`, `fact`, `statement`, and `end`.

Set a layout in per-slide frontmatter or use the matching layout component.
The `two-cols` layout supports `::right::` to begin the second column. Use
`cover` or `intro` for the title slide, and vary the layout to make a long deck
easier to scan.

Full upstream guide: https://sli.dev/guide/layout

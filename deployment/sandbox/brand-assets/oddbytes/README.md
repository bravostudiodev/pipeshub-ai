# OddBytes brand assets

These ready-to-use files are installed in `/opt/brand-assets/oddbytes/` in the
coding sandbox. Use them only when OddBytes branding is requested, and follow
the applicable brand guide.

Each logo and icon is available as a self-contained SVG and as a transparent,
pre-rendered PNG with the same filename stem. Use the PNG directly for PPTX or
other tools that need raster images; use the SVG for scalable web and Slidev
output. No SVG CSS repair or image conversion is required.

| Asset | Black / light background | White / dark background |
| --- | --- | --- |
| Full logo with orange accent | `OB_Black_Primary_Logo.svg` / `.png` | `OB_White_Primary_Logo.svg` / `.png` |
| Full monochrome logo | `OB_Black_Logo.svg` / `.png` | `OB_White_Logo.svg` / `.png` |
| Icon with orange accent | `OB_Black_Primary_Icon.svg` / `.png` | `OB_White_Primary_Icon.svg` / `.png` |
| Monochrome icon | `OB_Black_Icon.svg` / `.png` | `OB_White_Icon.svg` / `.png` |

Here “Black / light background” means black artwork intended for a **light**
background, and “White / dark background” means white artwork intended for a
**dark** background. The primary accent is `#FD533C`. Logo PNGs are 2122 pixels
wide; icon PNGs are 1288 pixels wide. All PNGs retain transparent backgrounds.
The `Sticker-*.png` files are the supplied stickers. The icon is not a
replacement for the full logo. Inter is installed separately as a system font;
copy font files into browser presentation builds when needed.
